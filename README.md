# XOXGame

A futuristic **Cyberpunk-Themed Tic Tac Toe** game developed using **React Native**.

This project features animated backgrounds, sound effects, neon-themed glitchy designs, and smooth win/draw animations, offering a vibrant and energetic gaming experience.


---

# 🔊 Features

- ❄️ Cyberpunk-style design
- 🎨 Dynamic Lottie background animation (Neon Rain)
- 🎧 Background cyberpunk soundtrack with toggle button
- 🔴 Animated "X" and "O" pieces when winning or draw
- ✨ Glitch effect and flashing animations on win/draw messages
- 🔄 Animated custom "Play Again" cyberpunk button
- ✅ Clean and smooth game reset functionality
- ⚡ Fast and light-weight experience


---

# 📒 Installation

```bash
git clone https://github.com/Enver-Onur-Cogalan/XOX-2049.git
cd XOXGame
yarn install
cd ios
pod install
cd ..
yarn ios  # or yarn android
```

---

# 🕹️ Usage

- Tap squares to place your "X" or "O".
- First to match 3 in a row, column, or diagonal wins.
- When the game is over, tap "Play Again" to restart.
- Use the sound toggle button (top right) to control background music.
